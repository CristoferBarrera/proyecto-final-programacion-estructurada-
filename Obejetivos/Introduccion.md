# Introducción

Actualmente la protección de información digital es una necesidad importante para los usuarios. El uso de mecanismos básicos de cifrado permite proteger archivos y evitar accesos no autorizados.

El presente proyecto consiste en un sistema desarrollado en ANSI C que permite:

- Crear cuentas de usuario.
- Iniciar sesión.
- Crear archivos de texto.
- Cifrar archivos.
- Descifrar archivos mediante el método XOR.

El proyecto fue desarrollado aplicando los temas vistos durante el curso de Programación Estructurada, incluyendo:

- Funciones.
- Arreglos.
- Archivos.
- Cadenas.
- Modularidad.
- Validaciones.
- Manejo de archivos TXT.
